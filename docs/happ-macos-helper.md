# Happ Desktop на Mac снова просит установить VPN helper

Эта памятка относится к **Desktop-сборке Happ из DMG**. Запрос пароля администратора для установки helper и предложение разрешить уведомления от VPN provider — разные окна. Если приложение просит только уведомления, эта памятка не объясняет причину сбоя подключения.

Проверено по публичным источникам 15 октября 2026 года. Конкретный сбой ниже сообщил пользователь Happ; воспроизведение на каждой версии macOS и исправление разработчиком пока не подтверждены.

## Сначала определите, какое приложение установлено

На [официальном сайте Happ](https://www.happ.su/main/ru) для macOS есть App Store и DMG. В документации разработчики отдельно различают Mac Catalyst из App Store и полную Desktop-сборку. Пункты, помеченные Desktop only, нельзя автоматически переносить между ними: [пояснение разработчика](https://github.com/HappDev/happ_su/blob/main/dev-docs/app-management.md).

Запишите версию macOS, версию Happ и источник установки. Если у вас App Store-сборка, не начинайте устанавливать или перезапускать `happd` по инструкции для DMG.

## Почему повторный запрос пароля ещё не доказывает отсутствие helper

В [публичном issue от 11 октября 2026 года](https://github.com/Happ-proxy/.github/issues/6) описаны Happ Desktop 4.2.1 build 236 и macOS 26.6.2. Автор наблюдал работающий `happd`, потерю связи между приложением и службой и повторный запрос установки. По его диагностике, ожидание загрузки подписки задерживало обмен служебными сообщениями.

Это конкретное наблюдение, а не установленная причина любого запроса пароля. Отдельный [issue о падении helper при завершении работы](https://github.com/Happ-proxy/.github/issues/7) тоже не означает, что служба отсутствует. Повторная переустановка без уточнения симптома может не помочь.

## Что проверить без изменения системной конфигурации

1. **Есть ли серверы в Happ?** Если список пуст после удаления конфигураций, сначала восстановите свою существующую подписку через её исходный сервис. Установка helper сама по себе список серверов не создаёт. Способы импорта описаны в [официальной инструкции](https://www.happ.su/main/ru/faq/adding-configuration-subscription.md).
2. **В какой момент появляется окно?** При запуске, обновлении подписки или нажатии подключения? Запишите точный текст. Уведомление provider, запрос прав администратора и ошибка импорта требуют разных проверок.
3. **Видна ли служба?** В «Мониторинге системы» можно найти процессы Happ и `happd`. Наличие процесса не доказывает исправность туннеля, а его отсутствие в одном снимке не устанавливает причину. Пока только зафиксируйте наблюдение.
4. **Не зависло ли обновление подписки?** Сравните время начала обновления с появлением ошибки. Не отправляйте адрес подписки в публичные проверки URL. Если она не загружается, сначала сообщите об этом её провайдеру; не считайте каждую такую ошибку поломкой установки helper.
5. **Завершите обычный перезапуск приложения**, если оно отвечает: сохраните работу, отключите соединение и закройте Happ штатно. После открытия проверьте тот же симптом один раз. Если macOS или приложение зависли, не повторяйте установку по кругу — сохраните описание для поддержки.

Не удаляйте все VPN-профили, службы и подписки ради этого теста. Не отключайте проверку сертификатов, Gatekeeper или защиту системы. Не запускайте команды с `sudo`, скрипты ремонта или установщики из случайного комментария. Версия из нового release не считается исправлением этого issue без соответствующего подтверждения.

## Когда нужна другая диагностика

- **Нет конфигураций или подписка не импортируется:** сначала восстановите импорт. Новая покупка не является тестом локального helper.
- **Happ подключается, но страницы не загружаются:** это другой этап; есть [проверки передачи данных после подключения](https://net.wilwous.ru/guides/happ-connected-no-internet?utm_source=community&utm_medium=community&utm_campaign=happ-github-profile-import&utm_content=help).
- **Повторяется именно запрос установки helper:** приложите разработчику или своей поддержке сведения ниже. По одному сообщению нельзя определить, повреждена ли установка, потеряна ли связь со службой или зависло обновление.

## Что сообщить поддержке

```text
macOS: версия
Happ: версия и источник — App Store / Desktop DMG
Список конфигураций: есть / пуст
Ошибка возникает: запуск / обновление подписки / подключение
Точный текст окна без секретных данных:
Время события и часовой пояс:
Happ и happd в Мониторинге системы: что наблюдалось
После одного обычного перезапуска: результат
```

Не прикладывайте ссылку подписки, QR, UUID, токен личного доступа, пароль администратора или необработанный полный журнал. Если нужен журнал, сначала проверьте и скройте эти данные.
